Tips 的首个桌面预发布版，面向 Windows、macOS 和 Linux。`v0.1.0` 在 macOS 编译检查时被拦截，未公开 Release；本版补齐透明悬浮窗所需的 macOS 编译开关。

## 下载

- Windows x64：下载 `*-setup.exe` 安装程序。
- macOS Apple Silicon：下载 `*_aarch64.dmg`。
- macOS Intel：下载 `*_x64.dmg`。
- Linux x64：下载 `.deb` 或 `.AppImage`；AppImage 需要添加执行权限。
- `SHA256SUMS.txt` 包含所有安装包的 SHA-256 校验值。

当前 Windows 包未配置发行者签名，macOS 使用 ad-hoc 签名且未 notarize，系统可能要求额外确认。macOS 透明悬浮窗使用 Tauri `macos-private-api`，目前采用 DMG 分发，不适合 App Store 上架。Linux 需要支持 WebKitGTK 4.1 和 Secret Service 的桌面环境；中文显示依赖系统安装的中文字体。

## 本版功能

- 独立桌面便签、TODO 清单与临时密文，支持置顶、托盘恢复和持久化窗口状态。
- 清单逐项编辑与勾选，完成状态自动联动。
- 持久化分组、标签、搜索、归档箱与恢复。
- 浅色/黑金主题、六种便签背景色，文字和背景分别调节透明度。
- 简体中文、English 与跟随系统语言。
- 正文和清单项本机加密，主密钥保存在系统凭据库。
- 本机 MCP 服务、独立客户端令牌、分组授权、读写角色和显式分组管理权限。
- 普通便签、TODO、归档和空分组的 JSON 导入导出，支持基于 ID/revision 的合并。

## 当前边界

- 导出的进度 JSON 是明文；密文、敏感条目、MCP 令牌/授权和桌面窗口设置不会导出。
- 导入适合单设备接续工作。两台设备独立修改同一条目时，revision 不能完整识别分支历史；当前没有冲突对比或手工合并界面，也不传播删除。
- MCP 目前只监听本机 `127.0.0.1:4784`；LAN、stdio bridge、任务分配/认领和变更订阅尚未提供。
- 到期时间暂不触发系统提醒或自动清除。
- 归档可恢复；尚未提供归档箱永久删除、删除分组或独立工作区切换。
- 暂不支持 draw.io 渲染、图片/附件、自动云同步或应用内自动更新。
- 自动化构建和后端测试不能替代各平台安装、托盘与悬浮窗的真实桌面验收。
